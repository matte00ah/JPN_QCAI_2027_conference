# QCAI 2027 - hybrid quantum-kernel crater detection (proxy experiment)

Code and data of the preliminary experiment for the paper to the 2nd QCAI Workshop (IEEE QCNC 2027).
The experiment tests, on one lunar region, a hybrid crater detector: frozen foundation-model features
of LROC WAC optical images and SLDEM2015 elevation, a multimodal fusion layer, a classical first
stage and a quantum-kernel SVM (on simulator) that re-classifies the candidate sub-tiles, compared with
classical baselines on the same inputs.
The full plan, with steps, decisions and status, is in `JPN_QCAI_conference_plan.md`; a plain-language
account of the steps done so far and of their results is in `steps_and_results_summary.md`.

## Environment
Conda environment `mbulgarelli` (PyTorch with CUDA, timm, scikit-learn, Qiskit, Qiskit Aer,
qiskit-ibm-runtime, pandas, matplotlib, mthree, umap-learn, PyYAML). GPU jobs run on the SLURM
partition `gpuh100`. The DINOv2 ViT-S/14 weights (`timm` model `vit_small_patch14_dinov2.lvd142m`)
are in the Hugging Face cache `~/.cache/huggingface/hub/`.

The code reuses, by import, the dataset modules of the full project in `../Repository/Dataset/scripts/`
(PDS label parsing, readers with no-data handling and georeferencing corrections), and reads the
dataset inventory `../Repository/Dataset/Moon/preprocessing/sources/data_inventory.csv`.
